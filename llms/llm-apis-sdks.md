# LLM APIs & SDKs

## What Is It?

LLM APIs let you **integrate AI into your applications** by sending requests to hosted models and getting responses back. Think of it like calling any REST API — except the response is generated by an AI model instead of pulled from a database.

As a frontend developer, this is the most natural entry point — you already know how to call APIs, handle async operations, and build UIs around data.

## Frontend Analogy

```javascript
// You already do this:
const response = await fetch('/api/users', { method: 'GET' });
const users = await response.json();

// LLM APIs work the same way:
const response = await fetch('https://api.anthropic.com/v1/messages', {
  method: 'POST',
  headers: { 'x-api-key': ANTHROPIC_KEY, 'content-type': 'application/json' },
  body: JSON.stringify({
    model: 'claude-sonnet-4-5-20241022',
    max_tokens: 1024,
    messages: [{ role: 'user', content: 'Hello!' }]
  })
});
const data = await response.json();
console.log(data.content[0].text); // "Hello! How can I help you today?"
```

## The Major LLM APIs

### Anthropic (Claude)

```
Models:
  claude-opus-4-6       → Most capable, deep reasoning
  claude-sonnet-4-5-20241022  → Fast, great for coding (best value)
  claude-haiku-4-5-20251001   → Fastest, cheapest

Pricing (Sonnet):
  Input:  $3 / million tokens
  Output: $15 / million tokens

Key features:
  - 200K token context window
  - Extended thinking (step-by-step reasoning)
  - Tool use (function calling)
  - Vision (image understanding)
  - Structured outputs (guaranteed JSON)
  - Prompt caching (save $ on repeated context)
```

### OpenAI (GPT)

```
Models:
  gpt-4o        → Flagship multimodal model
  gpt-4o-mini   → Fast, cheap
  o1 / o3       → Reasoning models (think before answering)

Pricing (GPT-4o):
  Input:  $5 / million tokens
  Output: $15 / million tokens

Key features:
  - 128K context window
  - Function calling
  - Vision, audio, video
  - JSON mode / structured outputs
  - Fine-tuning available
```

### Key Differences

```
                    Claude                  GPT-4o
─────────────────────────────────────────────────────
Context window      200K tokens             128K tokens
Reasoning           Extended thinking       o1/o3 models
Coding              Excellent               Excellent
Safety              Constitutional AI       RLHF

Best for            Long docs, coding       General purpose
```

## Using the Anthropic SDK (TypeScript)

### Setup

```bash
npm install @anthropic-ai/sdk
```

```typescript
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,  // or set ANTHROPIC_API_KEY env var
});
```

### Basic Message

```typescript
const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5-20241022',
  max_tokens: 1024,
  messages: [
    { role: 'user', content: 'Explain React hooks in 3 sentences.' }
  ]
});

console.log(response.content[0].text);
// "React hooks are functions that let you use state and lifecycle features
//  in functional components..."
```

### With System Prompt

```typescript
const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5-20241022',
  max_tokens: 1024,
  system: 'You are a senior TypeScript developer. Give concise, practical answers with code examples.',
  messages: [
    { role: 'user', content: 'How do I debounce a function?' }
  ]
});
```

### Multi-turn Conversation

```typescript
// Conversations are stateless — you send the full history each time
const messages = [
  { role: 'user', content: 'My name is Vitaly.' },
  { role: 'assistant', content: 'Nice to meet you, Vitaly! How can I help?' },
  { role: 'user', content: 'What\'s my name?' },  // Tests memory
];

const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5-20241022',
  max_tokens: 1024,
  messages,
});
// → "Your name is Vitaly!"
// The model "remembers" because the full conversation is in the messages array
```

```javascript
// Frontend analogy: It's like a REST API with no sessions

// Traditional auth: server keeps session, you send session cookie
// LLM API: no session — you send the ENTIRE conversation every time

// It's like if localStorage was the only way to persist state,
// and you sent the full store with every API call
```

### Streaming (Critical for Chat UIs)

```typescript
// Without streaming: user waits 5 seconds, then sees entire response at once
// With streaming: user sees tokens appearing in real-time (like ChatGPT)

const stream = anthropic.messages.stream({
  model: 'claude-sonnet-4-5-20241022',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'Write a poem about coding.' }],
});

// Process tokens as they arrive
stream.on('text', (text) => {
  process.stdout.write(text);  // Print each token immediately
});

// Or collect the final message
const finalMessage = await stream.finalMessage();
```

### In a Next.js API Route

```typescript
// app/api/chat/route.ts
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic();

export async function POST(req: Request) {
  const { messages } = await req.json();

  const response = await anthropic.messages.create({
    model: 'claude-sonnet-4-5-20241022',
    max_tokens: 1024,
    stream: true,  // Enable streaming
    messages,
  });

  // Return as a ReadableStream for the frontend
  return new Response(response.toReadableStream(), {
    headers: { 'Content-Type': 'text/event-stream' },
  });
}
```

```typescript
// Frontend component consuming the stream
'use client';

async function sendMessage(input: string) {
  const res = await fetch('/api/chat', {
    method: 'POST',
    body: JSON.stringify({ messages: [{ role: 'user', content: input }] }),
  });

  const reader = res.body?.getReader();
  const decoder = new TextDecoder();

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    const text = decoder.decode(value);
    // Append to UI in real-time
    setResponse(prev => prev + text);
  }
}
```

## Structured Outputs (Guaranteed JSON)

One of the most important features for building apps. The model is **guaranteed** to return valid JSON matching your schema.

```typescript
// Using Anthropic's tool use for structured output
const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5-20241022',
  max_tokens: 1024,
  tools: [{
    name: 'extract_info',
    description: 'Extract structured information from text',
    input_schema: {
      type: 'object',
      properties: {
        name: { type: 'string', description: 'Person name' },
        email: { type: 'string', description: 'Email address' },
        sentiment: { 
          type: 'string', 
          enum: ['positive', 'negative', 'neutral'],
          description: 'Overall sentiment' 
        },
        topics: { 
          type: 'array', 
          items: { type: 'string' },
          description: 'Main topics mentioned' 
        },
      },
      required: ['name', 'email', 'sentiment', 'topics'],
    }
  }],
  tool_choice: { type: 'tool', name: 'extract_info' },  // Force this tool
  messages: [{
    role: 'user',
    content: 'Email from John (john@acme.com): "Love the new dashboard! The analytics features are exactly what we needed."'
  }],
});

// Response is guaranteed valid JSON matching the schema:
const result = response.content[0].input;
// {
//   name: "John",
//   email: "john@acme.com",
//   sentiment: "positive",
//   topics: ["dashboard", "analytics"]
// }
```

## Prompt Caching (Save Money)

If you send the same system prompt or context with every request, prompt caching avoids re-processing it each time.

```typescript
// Without caching: 200K tokens of context × 100 requests = 20M input tokens ($60)
// With caching: 200K tokens cached + 100 × small query tokens = ~$6 (90% savings)

const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-5-20241022',
  max_tokens: 1024,
  system: [
    {
      type: 'text',
      text: hugeDocumentation,   // 50K tokens of context
      cache_control: { type: 'ephemeral' },  // ← Cache this!
    }
  ],
  messages: [{ role: 'user', content: 'How do I deploy?' }],
});

// First request: full price (cache miss)
// Next requests within 5 min: 90% cheaper (cache hit)
```

```javascript
// Frontend analogy: It's literally HTTP caching / CDN caching

// Without cache: every request hits the origin server (expensive)
// With cache: CDN serves the cached response (cheap, fast)

// Prompt caching = CDN for your LLM's input processing
```

## The Vercel AI SDK (Framework-Agnostic)

The Vercel AI SDK is a popular choice for frontend developers building chat UIs. It works with multiple providers.

```bash
npm install ai @ai-sdk/anthropic
```

```typescript
// app/api/chat/route.ts — Next.js App Router
import { anthropic } from '@ai-sdk/anthropic';
import { streamText } from 'ai';

export async function POST(req: Request) {
  const { messages } = await req.json();

  const result = streamText({
    model: anthropic('claude-sonnet-4-5-20241022'),
    system: 'You are a helpful coding assistant.',
    messages,
  });

  return result.toDataStreamResponse();
}
```

```tsx
// app/page.tsx — React component
'use client';
import { useChat } from 'ai/react';

export default function Chat() {
  const { messages, input, handleInputChange, handleSubmit } = useChat();

  return (
    <div>
      {messages.map(m => (
        <div key={m.id}>
          <strong>{m.role}:</strong> {m.content}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input value={input} onChange={handleInputChange} />
        <button type="submit">Send</button>
      </form>
    </div>
  );
}
```

## Error Handling & Best Practices

```typescript
import Anthropic from '@anthropic-ai/sdk';

const anthropic = new Anthropic();

async function safeLLMCall(prompt: string) {
  try {
    const response = await anthropic.messages.create({
      model: 'claude-sonnet-4-5-20241022',
      max_tokens: 1024,
      messages: [{ role: 'user', content: prompt }],
    });
    return response.content[0].text;
    
  } catch (error) {
    if (error instanceof Anthropic.RateLimitError) {
      // 429 — Too many requests
      // Wait and retry (SDK has built-in retries)
      console.log('Rate limited, retrying...');
      
    } else if (error instanceof Anthropic.APIError) {
      // Other API errors (400, 500, etc.)
      console.error(`API Error: ${error.status} ${error.message}`);
      
    } else {
      throw error;
    }
  }
}
```

### Cost Control Tips

```typescript
// 1. Use the cheapest model that works
// Don't use Opus for simple classification — Haiku is 60x cheaper

// 2. Set max_tokens appropriately
// Don't set max_tokens: 4096 if you expect a one-word answer
max_tokens: 100  // For short answers

// 3. Use prompt caching for repeated context
cache_control: { type: 'ephemeral' }

// 4. Stream to improve perceived latency
// Users see tokens immediately instead of waiting for full response

// 5. Batch non-urgent requests
// Anthropic's batch API is 50% cheaper for async processing
const batch = await anthropic.messages.batches.create({
  requests: [/* array of message requests */]
});
```
